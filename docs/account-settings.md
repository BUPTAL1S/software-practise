# 登录与账号资料

## 使用

- 启动客户端后先显示登录页，填写账号、密码并点击「登录并上线」。后台认证通过后进入聊天界面，自动启动引擎并发起 SIP 注册。
- 本机检测到 SIP 服务时使用 `127.0.0.1`。其他机器默认使用 `10.21.233.158`；不会沿用从主机复制的 `localhost` 设置。
- 后台自动探测 8080、8088、8081、8082、8083。高级「连接设置」可手动覆盖地址；成功连接后保存地址，不把密码写入本地偏好文件。
- 点击左侧头像打开「我的账号」，可修改昵称、修改密码或进入头像编辑。
- 点击「设置」底部的「退出登录」，结束当前通话/会议并释放 SIP 引擎，调用已有 `/api/logout` 退出当前后台会话，再返回登录页。保留账号和连接设置，清空密码；下一次登录使用新的前端会话，不沿用上一账号的聊天界面状态。退出和登录页不会触发后台自动重登。
- 设置表单可滚动，底部操作区固定显示，缩小窗口时仍可点击退出登录。这些改动仅涉及前端，未修改 Kamailio、FreeSWITCH、原生库或后台接口。
- 昵称为 1–32 个字符；账号、SIP 标识不变，聊天路由与历史记录仍使用原编号。通讯录轮询刷新昵称，通话窗口采用通讯录名称。
- 密码修改需要正确的原密码，新密码至少 6 个字符、UTF-8 编码最多 72 字节。成功后当前客户端更新凭据，其他旧会话失效。
- `1001` 保持 ADMIN，其他用户不能通过资料接口设置角色或修改别人的资料。

## 后台

此前后端只有登录、注册与头像管理，没有昵称或密码修改。现在增加：

- `GET /api/me`：附带 nickname、role。
- `PATCH /api/me/profile`：Bearer 认证，只修改调用者的 nickname。
- `POST /api/me/password`：currentPassword、newPassword；验证原密码，哈希保存新密码，撤销该用户的旧 token，并返回当前客户端的新 token。
- `/api/users`、`/api/login` 返回 nickname；登录还返回 role。

users 表新增可空的 nickname 字段，由现有 Hibernate schema update 添加。已有用户未设置昵称时回退为账号编号，无须重建数据库。

当前 Kamailio 配置没有开启 SIP 密码鉴权；上述密码修改针对后台账号认证。客户端下次注册会采用内存中更新的密码，但这次没有改动 SIP 服务的鉴权架构。

## 验证

后台 18 项测试覆盖新资料接口及已有登录、私聊和聊天室管理员权限。密码测试使用 target 下独立数据库，不更改真实账号密码。
客户端检查覆盖自动选址、HTTP 昵称/密码接口与 token 轮换、昵称特殊字符解析、登录提交与截图，以及小窗口下可滚动访问密码表单。
`LogoutFlowTest` 使用独立测试 HTTP 服务验证重复点击只退出一次、连续两次退出返回登录页、密码清空、会话数据隔离，以及返回登录页后不自动认证。加 `-Dsip.logoutNativeTest=true` 可验证真实原生引擎在专用本机端口上的启动和释放，不注册真实账号。

头像回归测试使用 `target/test-avatar.db`、`target/test-avatars` 和 `target/test-avatar-uploads`，
默认不连接运行中的 FreeSWITCH。MCU 实机验证需显式启用 `sip.liveMcuTest` 并配置专用测试环境的头像映射目录；
测试使用唯一的临时会议名，只清理该测试会议，不执行全局挂断。
