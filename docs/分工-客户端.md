# 分工：客户端

负责 PC 桌面端。Windows 与 macOS 共用一份 Java 代码。

## 做

- JavaFX 界面：登录、联系人、一对一通话、加入房间、文字、发文件
- PJSUA2：REGISTER、一对一 INVITE、`INVITE sip:room-<id>@lab`、SIP MESSAGE
- 按 OS 加载 `native/windows-x64` 或 `native/macos-arm64` 里的 `pjsua2`
- 文件走后台 HTTP，不在 SIP 里传二进制
- 一对一失败时不要自动改打 MCU

## 不做

- 不配 Kamailio / FreeSWITCH
- 不写管理端页面
- 不实现 MSRP、不接 Jitsi
- 不把 `.dll` / `.dylib` 提交进 git

## 接口

- SIP 域、账号格式：见 [整体规划.md](整体规划.md)
- 登录与文件：`POST /api/login`、`POST /api/files`（路径以后台为准，本角色不要自己再开一套存储）
- 房间号只使用后台返回的 `room-<id>`，不要客户端本地编 URI
