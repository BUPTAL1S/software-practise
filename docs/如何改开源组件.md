# 如何改开源组件

不把上游源码推进课设仓库，不等于电脑上不能有源码。课设要改的是我们的 cfg 和 Java，不是 Kamailio / PJSIP 的 C 树。

```
提交进本仓库：client/  Java、server/kamailio cfg、server/freeswitch xml、admin/
本机另目录或 Docker、不入库：pjproject 2.17 源码、Kamailio/FreeSWITCH 镜像
```

| 组件 | 实际改哪里 | 上游 git 进课设仓？ |
|---|---|---|
| Kamailio | `server/kamailio/`（REGISTER、1:1 relay、`room-` 前缀） | 不要。镜像跑官方二进制，volume 挂我们的 cfg |
| FreeSWITCH | `server/freeswitch/`（max-members=8、3×3、ESL） | 不要 |
| PJSIP | `client/` 里 Java 调 PJSUA2；JNI 编好放到 `native/`（gitignore） | 不要。源码克隆到仓外，例如 `~/src/pjproject` |
| Spring / ESL | 自己写 `admin/`，Maven 拉 esl-client | 不要 fork OpenCallHub |

改完 Kamailio/FS 配置后 `docker compose up` 即生效，不必重编代理。

## Kamailio / FreeSWITCH

compose 已把本仓目录挂进容器：

- `./kamailio` → `/etc/kamailio`
- `./freeswitch` → `/etc/freeswitch`

在本仓库编辑这些文件，重启对应容器即可。不要 `git clone` Kamailio 进 `software-practise`。

## PJSIP（只为编 JNI）

仓外克隆 2.17，按官方 Java SWIG 文档编译，把产物拷到本仓 `native/`（不提交）：

```bash
git clone --branch 2.17 --depth 1 https://github.com/pjsip/pjproject.git ~/src/pjproject
# 然后按 https://docs.pjsip.org/en/latest/pjsua2/building.html 编 Java 模块
# Windows: 拷到 native/windows-x64/pjsua2.dll
# macOS arm64: 拷到 native/macos-arm64/libpjsua2.dylib
```

只有 JNI 编不过、必须改 C 时才动 `~/src/pjproject`。若补丁要给组员，放到 `native/patches/`，不要把整棵 pjproject 推进本仓库。
