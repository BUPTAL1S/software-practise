# 管理工作台登录、刷新与权限

## 管理员入口

通过后台的 `/admin.html` 打开工作台，`/` 和 `/index.html` 自动转向同一入口。
账号必须同时满足用户名为 `1001`、角色为 `ADMIN`。不在页面预填或保存密码。
浏览器标签页通过 `sessionStorage` 保存自己的会话，刷新页面时先验证会话，再请求管理数据。

工作台使用 `/api/admin/login`、`GET /api/admin/session`、`POST /api/admin/logout`。
退出仅撤销当前浏览器的 token，不撤销同账号桌面客户端的其他 token。
收到 401/403 时清空会话、表格和表单，返回登录界面；此前发出的请求不能再写回旧数据。

## 接口边界

- `/api/admin/workbench/**`、聊天审计 `/api/admin/messages` 和 `/api/admin/room-messages`
  都由统一的 `ApiAccessPolicy` 检查管理员身份，不能只靠页面隐藏功能。
- 旧的全局文件列表、在线会话列表、话单详情、`POST /api/users` 同样要求管理员，防止绕过新页面。
- 用户删除通过 `DELETE /api/admin/workbench/users/{id}`，兼容 `DELETE /api/users/{id}`；两条路径均按同一管理员规则鉴权。管理员账号不可删除；成功后撤销目标全部后台会话，客户端轮询通讯录移除联系人，历史记录保留。
- 客户端通讯录 `GET /api/users`、用户详情、房间目录及 `GET /api/health` 继续公开；
  `POST /api/register` 保留客户端自助注册用途，不接受管理员角色设置。
- 客户端房间创建、心跳、聊天、视频状态、文件上传及话单接口需要有效登录。
  普通用户可继续创建房间和查询自身话单，不能查询他人话单或冒用他人身份上传文件、上报话单。
  话单按通话参与者鉴权，主叫和被叫都可上报同一 Call-ID，保留真实方向并合并有效较大时长；不能借用其他通话的 Call-ID 修改记录。
  新注册账号的用户名和分机号不能占用其他账号的任何身份别名；完整 SIP 地址按分机号核验。
- 工作台的文件列表和 `/api/admin/workbench/files/{id}` 管理下载要求管理员 token。
  客户端原有 `/api/files/{id}` 公开文件地址保持不变（含 `HEAD`），因为 JavaFX 头像和聊天图片直接请求该地址。
  本轮不改变客户端文件分享模型；若要限制文件内容的读取，需要配套升级客户端图片加载及历史文件链接。
- 客户端原有的已登录汇总统计接口继续保留。HTTP 会话数只表示有效后台会话，不表示 SIP 注册或在会人数。

这些调整不修改数据库结构，不涉及客户端原生视频或 MCU 配置。

## 页面行为

- 所有动态字段通过文本节点显示；不把房间名、文件名、聊天内容、Call-ID 等拼成 HTML 或内联事件。
- 下载地址由受保护的接口路径和文件 ID 生成，忽略记录中的任意 URL；下载请求携带管理员 token。
- 每轮更新顶部状态、汇总信息和当前栏目；隐藏页面时暂停自动轮询，恢复可见后更新。
- 同一资源不重复轮询，用户改变查询时取消旧请求；旧响应、过期会话的响应不能覆盖当前内容。
- 未变化的行复用 DOM，保留筛选值与表格滚动位置。请求失败保留旧数据并标注失败及最近更新时间。
- 后台连接、ESL 连接分别显示；无法获取会话列表时显示“状态未知”，不把失败当成离线。
- 房间容量固定为当前 MCU 支持的 8 人；创建和注册按钮在提交期间禁用；复制失败明确提示失败。

## 隔离验证

JDK 17 和 Maven 环境下执行：

```text
mvn -o -f admin/pom.xml test
node --test admin/src/test/js/admin-workbench.test.cjs
```

后台测试使用 MockMvc，不监听项目端口；默认测试数据库、头像和上传文件都保存在 `admin/target`，
ESL 默认关闭。真实 MCU 画布测试仍需显式开启，本轮未运行。

浏览器测试只启动无界面 Chrome 和随机本机端口的假接口，不启动 Spring Boot、JavaFX 客户端或容器。
Windows 默认寻找 `C:/Program Files/Google/Chrome/Application/chrome.exe`；
其他安装位置可通过 `CHROME_PATH` 指定，Node.js 需要支持内置 `node:test`。

覆盖管理员/普通用户/未登录/过期会话、旧接口权限、桌面会话不被浏览器退出撤销、动态文本安全、
表格复用、查询竞态、重复提交、断线与恢复、页面隐藏暂停、下载身份和复制失败。
用户管理另覆盖管理员保护、删除取消、失败重试、重复点击只提交一次，以及删除后的列表更新。
